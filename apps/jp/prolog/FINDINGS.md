# Prolog の日本語実装 検証記録

## 実行環境と結果

処理系は SWI-Prolog version 9.2.9 for x86_64-linux、テストは同梱の plunit です。`make test` は 19 件すべて passed です。

```text
% [12/19] 基本変換:3を渡したらFizzを返す ........................ passed (0.000 sec)
% [19/19] 基本変換:3を FizzBuzz変換 の順で書ける ................. passed (0.000 sec)
```

表示幅を文字数で計算しているため、日本語のテスト名では点線の桁がそろいません。

## 日本語にできた名前・できなかった名前

### できた名前

- 述語名: `装飾/2`・`タイプ生成/2`・`安全変換/2`
- モジュール名とファイル名: `:- module(基本変換, …)` ↔ `src/基本変換.pl`、`test/基本変換.plt`
- 項の名前: `タイプ(通常, 'FizzBuzz変換')`・`成功("Fizz")`・`失敗(…)`・`タイプエラー(…)`
- アトム `通常`・`数字限定` を引用符なしで列挙子のように使える
- plunit のユニット名 `begin_tests(基本変換)` とテスト名 `test('3を渡したらFizzを返す')`。引用符付きアトムなので空白も入る

### できなかった名前

- 日本語で始まるトークンはアトムになるため、**日本語の変数は作れない**。`結果 = 3` はエラーにならず単に失敗する。実装途中で節の頭を `結果 は 値 を 手順 :- …` と書いた際は、すべてがアトムとして扱われ、エラーなしでテストだけが失敗した
- `FizzBuzz変換` は ASCII 大文字で始まるため変数と解釈される。引用符なしの `FizzBuzz変換(3, R)` は `Syntax error: Operator expected`
- 助詞と後ろの日本語はつなげて書けない。`'FizzBuzz変換'して装飾` の `して装飾` は 1 つのアトムになり `Syntax error: Operator expected`。一方 `3を` は数値の後なので空白なしで書ける

## 採用した回避策とその代償

| 回避策 | 代償 |
|--------|------|
| 日本語の変数に `_` を付ける（`_結果`・`_数`） | 先頭に ASCII 記号が付く。SWI-Prolog は `_小文字` と同様に通常の変数として扱うため、1 回しか使わないと `Singleton variables: [_数]` と警告する（`_Abc` は警告なし） |
| 全角英大文字で始める（`Ｒ`） | 変数として動くが、表記揺れの原因になるため不採用 |
| `'FizzBuzz変換'` のように引用符で囲む | ASCII 大文字で始まる名前には毎回引用符が必要 |
| Makefile で `LANG`・`LC_ALL` を `C.UTF-8` に設定 | LANG=C では下記のとおり異常終了する |

LANG=C で `swipl -q test/run.pl` を実行した結果です（終了コード 134）。

```text
Warning:    '…/test/run.pl':2:30: Illegal multibyte Sequence
[Thread 1 (main) …] /build/source/src/os/pl-glob.c:494: mb_add_path___LD: Assertion failed: 0
```

## 語順の再現

助詞を演算子として定義すると、なでしこ3 に最も近い語順で書けます。

```prolog
:- module(語順, [(は)/2, op(700, xfx, は), op(200, xfx, を), op(100, xfy, して)]).
:- meta_predicate は(?, :).

_結果 は _モジュール:(_値 を _手順) :- 適用(_手順, _モジュール, _値, _結果).
適用(_前 して _後, _モ, _値, _結果) :- !, 適用(_前, _モ, _値, _途中), 適用(_後, _モ, _途中, _結果).
適用(_手順, _モ, _値, _結果) :- call(_モ:_手順, _値, _結果).

'FizzBuzz装飾'(_数, _結果) :- _結果 は _数 を 'FizzBuzz変換' して 装飾.
```

`meta_predicate` を付けないと、`'FizzBuzz変換'` が呼び出し元ではなく `語順` モジュールの中で探されます。

## lint の反応

- `make lint` は各 src ファイルを `swipl -q --on-warning=status -g halt` で読み込む。日本語の述語・モジュールに警告は出ず `lint: OK`
- 既存 `apps/prolog` の `-g "halt(0)"` では警告があっても終了コードが 0 になるため、こちらでは `--on-warning=status` に変えた（警告があると `Halting with status 1 due to 0 errors and 1 warnings`）
- formatter は既存と同じく使っていない

## 日本語化スコア

| 軸 | 点数 | 根拠 |
|----|------|------|
| 関数・変数名 | 1 | 述語名は可。変数は `_` 接頭辞が必要で、英大文字始まりの名前は引用符が必要 |
| 型・モジュール名 | 3 | モジュール・ファイル・項の名前・アトム（列挙子相当）がすべて可 |
| テスト名 | 3 | 引用符付きアトムで空白込みの文章を書ける |
| 語順の再現 | 3 | `_結果 は 3を 'FizzBuzz変換' して 装飾` |
| ツール許容 | 3 | UTF-8 ロケールなら plunit と読み込み検査が設定なしで通る |
| **合計** | **13** | |
